## 💡 アプリの概要・作った背景
従来の解析コードでは解析のたびにスクリプトを実行したり、条件を変えるために直接コードを書き換えたりする手間があり、UI/UXの観点では日常的なデータ確認において少しハードルがありました。

「自分のノートPCで、実験直後にサクッとデータを読み込んで、もっと直感的にピーク位置（回折角 $2\theta$ ）を確認したい」という思いから、従来の解析ロジックを活かしつつ、ブラウザ上で軽量に動く本アプリを開発しました。

開発にあたっては単にGUI化するだけでなく、**「使いやすさ」「見やすさ」**、そして毎日のルーチンワークであるデータ解析が少しでも**「楽しくなる」ようなモダンな操作性**を徹底的に重視しています。結果として、直感的なデータプレビューが可能になり、研究室での作業効率化に貢献しています。

## ✨ 主な機能
- **ファイルのドラッグ＆ドロップ**: 測定装置から出力されたファイルをそのまま読み込み
- **インタラクティブなグラフ描画**: マウスで特定のピーク領域を自在に拡大・縮小可能
- **自動ピーク検出**: 
- **結晶子サイズの計算**: 
- **画像エクスポート**: 進捗報告の資料用に、グラフをPNG形式でワンクリックでダウンロード

## 🛠 使用技術
- **Python 3.10**
- **Streamlit**: Webアプリケーション化
- **Pandas**: データの読み込み・前処理
- **SciPy**: データの平滑化（スムージング）およびピーク検出
- **Plotly** (または Matplotlib): インタラクティブなグラフの描画
